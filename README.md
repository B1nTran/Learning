# English 12 Quiz · Global Success

Bài tập trắc nghiệm Tiếng Anh 12 – Global Success, ôn tập **Units 1, 2, 3** với **90 câu hỏi**.

🌐 **Làm bài trực tuyến:** https://b1ntran.github.io/Learning/

## Tính năng

- 90 câu hỏi chia theo 3 unit, chấm điểm ngay sau khi nộp
- Thanh công cụ cố định trên cùng: **Đảo câu**, **Nộp bài**, **Làm lại**
- Thanh tiến độ và thống kê kết quả theo từng unit
- Giao diện sáng/tối, responsive cho điện thoại
- Không dùng thư viện ngoài, tải nhanh
